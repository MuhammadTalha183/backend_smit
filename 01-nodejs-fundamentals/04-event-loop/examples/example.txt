--- PART 3: blocking the Event Loop ---
Timer scheduled for 100ms. Now blocking the main
thread with a busy loop for about 300ms...
Busy loop done. (x = 3404450)
Timer fired after 300ms, not 100ms.
The loop was blocked, so the timer could not fire
on time - it waited for the busy loop to finish.

--- PART 4: async I/O does not block the loop ---
Starting a slow async file read, then a 50ms timer.
File read done (4248 chars).
Timer fired after 50ms - on time,
even though the file read was still running.
The read happened in the Thread Pool, not on
the main thread, so the loop stayed free.

Lesson: the Event Loop is a traffic controller,
not a worker. Keep it free, and Node.js stays fast.

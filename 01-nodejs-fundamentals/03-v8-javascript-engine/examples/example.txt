--- PART 3: Hidden Classes / Inline Caching ---
Same shape (2M reads): 4.036ms
Changing shape (2M reads): 16.056ms
Total (to stop V8 optimising the loop away): 6000000
Same shape = one hidden class, one fast inline cache.
Changing shape = V8 must look up x and y every time.
Rule: always add properties in the same order.

--- PART 4: Garbage Collection ---
Heap before creating objects: 8 MB
Heap after creating 200,000 objects: 29 MB
Heap after dropping them + running GC: 7 MB
GC freed the memory. No free() call needed in JS.

Lesson: V8 runs JavaScript. V8 also cleans up after it.
Keep object shapes stable and types consistent, and
V8 can keep your code on the fast path.
